# CloudyPassport

Hộ Chiếu Mây: web app một trang giúp tổ bay tính giờ xe đón và giờ họp BRF theo base (HAN, SGN), vai trò và loại chuyến bay.

Quy tắc tính giờ dựa trên công cụ Time Calculator (cập nhật 21.04.2026): https://timecalcvna.github.io/tinhgio/
Mục cộng thêm 15 phút cho chuyến có ngủ lại là phần bổ sung của app.

Không có bước build. Mở `index.html` hoặc deploy bằng GitHub Pages.
